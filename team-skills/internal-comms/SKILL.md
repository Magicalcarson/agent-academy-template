# Internal Communications

## When to use this skill

Use this skill to write internal communications in the team's/organization's preferred formats:
- 3P updates (Progress, Plans, Problems)
- Team / company newsletters
- FAQ responses
- Status reports
- Leadership updates
- Project updates
- Incident reports

## How to use this skill

To write any internal communication:

1. **Identify the communication type** from the request.
2. **Load the appropriate guideline file** from the `examples/` directory:
    - `examples/3p-updates.md` - Progress/Plans/Problems team updates
    - `examples/company-newsletter.md` - team/company-wide newsletters
    - `examples/faq-answers.md` - answering frequently asked questions
    - `examples/general-comms.md` - anything else (status/leadership/project updates, incident reports, and any format not matching the three above)
3. **Follow the specific instructions** in that file for formatting, tone, and content gathering.

If the communication type doesn't match any existing guideline, ask for clarification or more context about the desired format.
